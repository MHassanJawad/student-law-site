## Required fields when a candidate is approved

Record source owner/contact, canonical root and item URL pattern, item identifier, document types, jurisdictions, earliest/latest observed dates, enumeration method, file formats, language, robots/terms review date and evidence, reuse/display decision, attribution wording, allowed request rate, retry policy, refresh cadence, maintainer, and last successful check. Re-review when the source changes its policy or structure.

The approved pilot scope permits selecting small samples after source-specific checks. No source above is approved for bulk import or public republication by this register.
