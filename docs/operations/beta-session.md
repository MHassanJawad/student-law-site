# Small student beta session

Use this script only after a hosted test environment, working recovery email, and a full account-data restore drill are ready. The current local seed is a two-record metadata sample, not a complete legal archive. Participants need no legal background. Give each person a disposable test account and ask them not to enter private client or case information.

## Tasks for each participant

1. On a phone, find `C.P.L.A. No.1285-K of 2023` in Case Law. Open the result and identify its official source link and the date the record was checked.
2. Try Citation search with `PLD`. Explain what the empty result means. Ask whether the interface makes clear that no verified reporter citation is in this sample.
3. Find the Contract Act sample in Statutes. Ask whether its `LOCAL SAMPLE` label and unknown legal status are clear.
4. Sign in, save the judgment citation, add a note and folder, sign out, sign back in, and find the saved item again.
5. Use only the keyboard to reach the search form, run a search, open a result, and return to search. Record any invisible focus or place where Tab gets stuck.

Observe without coaching. Record task completion, confusing labels, errors, device/browser, and approximate time per task. Ask: “What did you expect here?” and “What would you change first?” Do not collect passwords, search terms from personal matters, or screenshots containing personal information.

## Exit notes

Target three to five students on at least one phone and one desktop browser. File concrete issues with the page, steps, expected behavior, and actual behavior. Triage blocked tasks and misleading legal status before cosmetic feedback. A screen-reader pass on search, document, sign-in, and saved citations remains a separate accessibility gate. The project owner recruits participants and decides when a hosted test environment may be used; no participant should be sent to the current local-only site.
